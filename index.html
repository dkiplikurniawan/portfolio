The problem

Deaf and hard-of-hearing students and their hearing teachers had few practical BISINDO tools that run on an ordinary smartphone without sensor gloves. The 2023 recognition model and AR code were lost; the surviving V1 Flutter code is public on GitHub.

01 / 05 In the field
  1. 1.

    Camera input

    The phone's camera records a person signing. No gloves or sensors: the goal was an ordinary smartphone.

    Reported in thesis The public V1 code does not access the camera.

  2. 2.

    Landmark extraction

    Each frame is reduced to MediaPipe hand and pose landmarks: a few dozen coordinates instead of a full image, so the model needs far less data and computation.

    Reported in thesis

  3. 3.

    Temporal processing & gesture recognition

    Landmark sequences over time are classified as one of 26 dynamic BISINDO signs. The test split and signer independence are undocumented, so the reported accuracy is not a measure of performance on new signers.

    Reported in thesis

  4. 4.

    Accessible output & feedback

    Recognised signs become text and speech. In the other direction, a hearing person's speech is transcribed live on screen. AR sign visualisation was part of the thesis design.

Featured project · CALMQUEST: The Lost Light

CALMQUEST: Rest Is The Quest

An open-world 2D cozy game to unwind after work. Built solo in Godot 4.

Game development · HCI · Data science

Fun first, transparent always

Many “relaxation” apps measure people without explaining how, or lean on black-box AI that claims to know how someone feels. CALMQUEST takes the opposite path: a complete game with no fail states, where every adaptation is a named, documented, unit-tested rule and every research datum needs explicit consent.

Explainable adaptation

A glass box, not a black box

The Adaptive Comfort Engine is a deterministic module with no machine-learning model, so every rule can be read, tested and audited. It uses only what the player does on purpose: an optional 0–10 check-in, and their own choice of mode.

Why rules, not ML? With no player data yet, a model would be untestable and unexplainable. Rules form a transparent baseline that any future personalisation model has to beat.

Planned evaluation

The claim has to be earned with people

Does a 15-minute CALMQUEST session reduce state anxiety (STAI-S) in working adults more than a neutral video of equal length? A randomised, counterbalanced AB/BA crossover with 30 working adults: each person is their own control.
